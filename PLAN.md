### Core definitions (use these exactly)
- **Pressure (play):** any Pass Rush row with `pff_hit|pff_hurry|pff_sack == 1`. **Pressure (rusher snap):** same, per row.
- **Success:** 1st down `playResult >= 0.4*yardsToGo`; 2nd `>= 0.6*yardsToGo`; 3rd/4th `>= yardsToGo`.
- **Conversion:** `playResult >= yardsToGo`. **Big play:** `prePenaltyPlayResult >= 20`.
- **Blitz:** 5+ pass rushers. **Stunt:** play has ≥1 `pff_blockType == "SW"`.
- **Lost rep (blocker):** any of hitAllowed, hurryAllowed, sackAllowed, beatenByDefender == 1.
- **Defensive linemen for get-off:** `officialPosition in {DE, OLB, DT, NT}`, `getoff` not null and `< 2`.
